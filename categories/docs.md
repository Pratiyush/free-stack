## Notes

- **Ghost** was evaluated but excluded: Ghost CMS is open-source (self-host free), but Ghost(Pro) managed hosting starts at $15/mo with no free tier.
- **Docusaurus** and **Docsify** are static site generators, not hosted platforms -- pair with free hosting (GitHub Pages, Cloudflare Pages, Netlify) for a fully free docs stack.
- **GitBook** free tier is powerful for solo developers but locks out collaboration entirely.
- **Read the Docs** is the gold standard for open-source Python/Sphinx docs but also supports MkDocs.
- **Hashnode** is the most generous: truly free with custom domains, newsletters, and GitHub backup included.
