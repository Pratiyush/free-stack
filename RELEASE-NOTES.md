# Release Notes

## v0.1.0 — "First Light"

The first release of free-stack — a curated list of free tiers for developers.

### What's Inside
- **18 categories** covering hosting, databases, auth, AI/ML, email, storage, testing, and more
- **~160 verified entries** with specific limits, rate limits, and pricing page links
- **Table format** — consistent columns across all categories (not just bullet lists)
- **Verified dates** — every entry timestamped with verification month
- **Community-ready** — PR template, issue templates, link checker CI

### How It's Different
- Tables with specific limits (not vague "free tier available")
- One file per category (not one giant README)
- Rate limits documented (missing from every other list)
- Verified dates so you know if info is current
- Services that removed free tiers are explicitly excluded

### Stats
- 18 category files
- ~160 entries across all categories
- 19 commits, all by Pratiyush
- 7 services identified and excluded (dead/removed free tiers)
