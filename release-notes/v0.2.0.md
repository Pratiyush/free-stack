# v0.2.0 — Seed Catalogue

The first browsable catalogue: 50 hand-picked services across 10 categories, every card colored by its brand, every route live.

## What shipped

- **50 seed services across 10 categories** — `ai-apis`, `hosting`, `databases`, `auth`, `email`, `monitoring`, `storage`, `ci-cd`, `dns`, `search`. Each entry is a typed YAML record (not a Markdown row), validated at build time by the Zod schema from v0.1.0.
- **Brand-colored service cards** — every card's accent strip uses the service's `brand_color` (sourced from simpleicons.org's `hex` field). Logos render as full-color SVGs, not monochrome.
- **Logo asset pipeline** — `scripts/fetch-logo.mjs` pulls SVGs in mandatory order: simpleicons.org → freeicons.io → Lucide. `docs/logo-fallback.md` documents the search order and per-source license terms.
- **All site routes** — `/`, `/catalog`, `/service/[slug]`, `/category/[slug]`, `/sponsors`, `/submit`, `/about`, `/methodology`, `/404` (68 pages generated at build time).
- **4 reusable UI primitives** — `ServiceCard`, `TierBadge`, `CategoryChip`, `SearchBox` (all in `src/components/ui/`), plus a `/components-preview` page to inspect them in isolation.

## Notable design choices

- **Free-tier is the only product.** Service cards and category listings show what's free. Paid plans are mentioned only in a service's `Notes` section — never in the main comparison row.
- **No analytics, no tracker scripts, no outbound `?ref=`.** Every external link carries `rel="noopener noreferrer"`. View-source is honest.
- **Sponsor purple is contained.** Brand color appears only on `/sponsors` and the small footer link. The home page leads with editorial typography, not a SaaS hero CTA.

## What still uses the MD-era site

`freestack.is-a.dev` keeps serving the v1.0.0 Markdown site from `master`. The Astro build lives on the `rebuild/astro` branch + GitHub Pages preview path. Production cut-over happens at v0.5.0, after Sprint 3 migrates all 323 entries.
