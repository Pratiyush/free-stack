# v0.9.0 — Content Depth + View Modes

> Every service now carries its **full pricing breakdown** — every published tier, every feature, every signup URL — and the catalog can render as a grid or an info-dense table with inline-expand on row click. The hero is bigger, with the dateline + Issue № inline above the h1, a pull-quote sidebar, and a stronger 6-column wall of brand-colored logos.

## What shipped

### Content depth — every service, every tier

- **Schema bumped (additive)** — `src/content.config.ts` gains optional `features[]`, `cta_url`, and `billing` on each pricing tier, plus a service-level `paid_tier_highlights[]`. All 300 existing YAMLs validate unchanged.
- **271 of 300 services expanded** by 12 parallel content agents running in parallel. Each agent fetched the service's live pricing page, extracted every published tier (Free / Pro / Team / Enterprise), and wrote back features, signup URLs, and billing cadence.
- **29 services skipped** because their pricing pages are bot-blocked or JS-rendered (Cloudflare/Akamai interstitial or empty SSR). Skipped list: brevo, brevo-sendinblue, canva, coherence, crowdin, linode-akamai, meta-llama-api, papertrail, qodana-jetbrains, quay-io, render, sendbird, strapi-cloud, umami-cloud, vonage, youtrack. These get re-tried in Sprint 5 once the Playwright pricing-drift verifier lands (§5.PWR).

### New views

- **Grid ↔ Table toggle** on `/catalog` and every `/category/<slug>` page. Toggle persists to `localStorage` + URL (`?view=table` is shareable).
- **Info-dense table view** — sortable columns (Service / Category / Tier / Quotas / CC?), brand-color row accent when expanded, mono price formatting.
- **Inline-expand accordion** — clicking a table row reveals the service's summary, free-tier bullets, key facets, and CTAs **inline below the row** (no drawer overlay). Click again to collapse; Escape closes any open row. Only one row open at a time. Full keyboard parity (Tab to row, Enter / Space to toggle).

### Hero refinement

- **Bigger h1** — capped at 5.5rem (was 4.4rem). Brand-color italic emphasis on "honest" and "actually" pops harder. Fade-in via `@starting-style` for browsers that support it; respects `prefers-reduced-motion`.
- **Inline Issue №005 + dateline** — the masthead bar that lived as a separate strip now sits **inside** the hero, above the h1, with a horizontal rule and `VERIFIED <DATE>` mono uppercase.
- **Sidebar pull-quote** — italic Fraunces quote drawn from `ref/docs/CONVERSATION.md` ("a wall of crisp, monochrome logos that lights up in color as you hover — like a periodic table of the free internet"), with a 3px coral left rule.
- **Wall is 6 columns** (was auto-fill), service names visible by default (not hover-only), View Transition on click (`transition:name="card-<slug>"`).

## Notable design choices

- **No drawer overlay for table-view rows.** Per the v3-brief routing strategy, the canonical detail surface is `/service/[slug]` (with View Transitions). Inline-expand exists for *table* view as a fast scan affordance — opening a card from grid view still navigates to the detail page.
- **One row open at a time.** Reduces visual chaos in info-dense tables. Mirrors the dashboard.html pattern from `ref/design-experiments/`.
- **Coral stays disciplined.** Selection state + active filter chip + chevron-on-expand. Sponsor purple still confined to `/sponsors`.
- **`billing: usage-based`** added as an enum option — covers the 30+ services that don't fit monthly/annual/one-time (Twilio per-message, OpenAI per-token, etc.).
