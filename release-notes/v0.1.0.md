# v0.1.0 — Astro 6 Foundation

free-stack is rebuilt on Astro 6. This is the foundation release — scaffold, schema, CI, and the design system are all green, but no services have migrated yet (that lands in v0.5.0).

## What shipped

- **Astro 6 static site** with TypeScript strict mode, output: 'static'
- **Editorial design system** — Fraunces / Inter Tight / JetBrains Mono variable fonts, paper-cream palette, coral accent
- **Zod content schema** for services + categories with build-time validation
- **Maintenance scripts** — `pnpm validate`, `pnpm check-logos`, `pnpm new:service <slug>`
- **CI gate** — every PR runs `lint → validate → check-logos → build` and must be green to merge
- **Preview deploy** — `rebuild/astro` branch builds to a GitHub Pages preview path (the production site at `freestack.is-a.dev` keeps serving the MD-era HTML until the v0.5.0 cut-over)
- **Conventional Commits PR-title lint** — all PRs across the 5-sprint roadmap follow the convention from day 1
- **Locked taxonomy** — `docs/category-taxonomy.md` defines the final 27 category slugs/names/icons/order
- **Release workflow** — `CHANGELOG.md` reformatted to Keep a Changelog 1.1.0, `release-notes/` directory established

## Under the hood

- pnpm 10 + Node 22 (pinned via `.nvmrc`)
- Tailwind CSS v4 via Vite plugin
- `astro-pagefind` integration installed (search activates in v0.2.0 when 50 services land)
- `@astrojs/sitemap` and `@astrojs/rss` wired

## Migration notes

- This release does **not** change what visitors see at `freestack.is-a.dev`. The MD-era site keeps serving from `master` until v0.5.0.
- Contributors: from now on every change goes through the Astro workflow (YAML, not Markdown tables). Sprint 3 migrates the existing 319 entries.
- The legacy `[0.1.0]` MD-era entry in CHANGELOG.md has been renamed to `[0.1.0-md]` to disambiguate from this release.
