# v0.8.0 — Editorial Polish

> The catalog looks like an almanac now. Periodic-table cards with brand-colored head-bands, Issue №/dateline chrome on every service page, a wall-of-logos homepage hero, View Transitions between catalog and detail, and a real `/compare?slugs=…` route — all drawn from the 10-agent review of the design experiments in `ref/`.

## What shipped

- **Card library v2** — every service card now leads with a 4px brand-color head-band over a 9% brand-tinted hero zone. Logo in a framed white inset. Hanging em-dash bullets replace check-marks. Hover is border-color only (no jittery translate). "No CC" pill only renders when `facets.cc_required: true`. Token additions: `--color-paper-warm`, `--color-ink-softer`, `--color-ink-faint`.
- **Almanac chrome on `/service/[slug]`** — masthead with `§ <CATEGORY> · № <SERIAL>`, italic Fraunces h1, dateline rule (`VERIFIED <DATE> · ADDED <DATE>` in mono uppercase), roman-numeral section dividers (`i. Free tier`, `ii. Pricing`, `iii. Limits & notes`, `iv. Links`, `v. Tags`, `vi. Sources`), italic Fraunces brand-color Free row in the pricing table, footnote-style `sources` block.
- **Homepage hero** — masthead bar with Issue №005 / Verified date, paper-cream + soft coral radial tints, italic Fraunces h1 with brand-color emphasis ("One *honest* directory of free tiers that *actually* stay free."), stats as a definition list, 48-tile periodic-table wall-of-logos that lights up on hover.
- **View Transitions API** — `<ClientRouter />` in BaseLayout + `transition:name="card-<slug>"` on every service card. Catalog → service-detail navigations animate smoothly without a JS framework. Falls back gracefully on Safari < 18.
- **`/compare?slugs=…` real route** — shareable URL with picker (type-to-search across 300 services, click to add), max 4 services, sortable facet rows grouped by Overview / Quotas / Capabilities / Restrictions / Trial / Operational, remove buttons per column, URL state sync (back/forward works). All client-side from a pre-rendered JSON blob of the catalogue — no runtime backend.
- **Sticky filter bar on `/catalog`** — IntersectionObserver-based sentinel pattern. Filter bar gets a soft shadow when stuck to the viewport top; static below 720px. Coral focus-visible ring on tier buttons.

## Notable design choices

- **Periodic-table metaphor finally rendered.** Founding doc `ref/docs/CONVERSATION.md:18` called for "a wall of crisp, monochrome logos that lights up in color as you hover — like a periodic table of the free internet." Homepage now does exactly that.
- **Coral stays disciplined.** Selection state + primary CTA only. Sponsor purple still confined to `/sponsors`. Brand colors are per-card, never global.
- **No new dependencies.** Astro's built-in `<ClientRouter />` does the View Transitions; everything else is hand-rolled vanilla.
- **Print-friendly.** All chrome reads on paper: serif h1, mono dateline, no hover-only affordances.
