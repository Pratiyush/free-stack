# v0.5.0 — Full Migration

> **Status: DRAFT.** Sprint 3 is still in flight. This file is updated as stories merge and finalised at tag time. Do not publish the release until the §"Sprint-Level Definition of Done" checklist in `docs/sprints/sprint-3.md` is fully ticked.

Every free-tier service free-stack tracks is now a typed YAML record. The legacy 27 Markdown tables are gone; categories carry subsection structure; pricing-drift is checked automatically against the live page; production cuts over from the static HTML to the Astro build.

## What shipped

_Update each bullet with final stats at tag time. Sentinel values shown in brackets._

- **Catalog migrated** — `[302+]` services across 27 categories, every entry a Zod-validated YAML record in `src/content/services/`. The 50 v0.2.0 seeds were preserved; `[252+]` new services arrived from the legacy `categories/*.md` tables.
- **Brand-colored cards everywhere** — every service has a `brand_color` sourced from simpleicons.org (or a documented fallback for the `[≈10-15%]` of services with no simpleicons entry). Cards in `/catalog` and `/category/*` render with full-color logos and a brand-tinted accent strip.
- **Subcategory rendering on category pages** — `/category/<slug>` now lays out three sections (Permanent Free Tiers / Free Credits & Trial / Severely Limited) matching the structure of the legacy MD tables.
- **Pricing-drift verification** — `pnpm verify-pricing` runs a Playwright text-presence check against every service's live pricing page. Both free-tier limits and paid plan prices are checked; sunset phrases (`no longer offer`, `discontinued`, `free tier ended`) hard-fail. Catches the moment a vendor cuts a tier.
- **SEO & syndication** — sitemap (`sitemap-index.xml`, `sitemap-0.xml`), RSS feed (`rss.xml`, 50 most-recently-verified services), Schema.org `SoftwareApplication` JSON-LD on every `/service/<slug>` page.
- **Legacy Markdown retired** — `categories/*.md` deleted; `README.md`, `CONTRIBUTING.md`, and `CLAUDE.md` rewritten to describe the YAML-first workflow.
- **Production cut-over** — `freestack.is-a.dev` now serves the Astro build (the previous static HTML build remains in history; rollback is a GitHub Pages branch toggle away).

## Notable design choices

- **Free-tier is the only product**, still. Subsection grouping makes the distinction between *permanent* free tiers, *expiring credits*, and *severely limited* explicit on every category page. Paid plans appear only in the per-service `pricing` table and the JSON-LD `Offer`.
- **Text-presence pricing verification, not strict scraping.** Pricing pages reshape weekly; a CSS-selector scraper would break in days. Playwright reads the rendered text, normalizes it, and asks "do the values I claimed still appear?" — robust to layout reshapes, fragile only to genuine drift.
- **No new tracking, no `?ref=`, no analytics scripts.** Visitor count remains zero, by design (Cloudflare Web Analytics lands as opt-in in Sprint 5).

## Migration impact for contributors

- **All future service edits go through YAML.** Open `src/content/services/<slug>.yml`, edit, run `pnpm validate && pnpm audit-services --no-http`. The legacy MD edit workflow is gone.
- **Adding a service**: `pnpm new:service <slug>` scaffolds a stub YAML; see `CONTRIBUTING.md` for the full submission flow.
- **CI gates**: `pnpm lint && pnpm validate && pnpm check-logos && pnpm audit-services --no-http && pnpm build` must all pass on every PR.
- **`pnpm verify-pricing`** runs on a monthly cron once Sprint 5 story 5.3 ships; for now it's a sprint-time gate.

## Breaking changes

- **`categories/*.md` deleted.** Anyone scraping the raw Markdown files needs to switch to the YAML at `src/content/services/`, the build artifact `data/index.json` (attached to this release), or the RSS feed.
- **URL surface expanded.** New routes per service and per category: `/service/<slug>`, `/category/<slug>`. Old URLs (anchor links into `docs/index.html`) get 301-redirects via Cloudflare Page Rules — verify against `docs/redirects.md` (added in story 3.13).
