# v0.5.0 — Full Migration

> **Status: DRAFT.** Sprint 3 is still in flight. Stories 3.7 (logo gaps) + 3.12 (legacy MD deletion) + the v4 Astro catalog port are the remaining gates. The production cut-over (story 3.13) is deferred to a later release. This file gets stat-updated and gates-ticked at tag time.

Every free-tier service that free-stack tracks is now a typed YAML record. The legacy 27 Markdown tables are deleted; categories carry subsection structure; pricing-drift is checked against the live page in a single sprint-time sweep; the schema gains optional `facets` (quantitative comparison) and `sources` (per-record provenance) blocks for the comparison-table renderer.

## What shipped

- **Catalog migrated** — **300 services across 27 categories**, every entry a Zod-validated YAML record in `src/content/services/`. The 50 v0.2.0 seeds were preserved; 252 new services arrived from the legacy `categories/*.md` tables; 2 confirmed-dead services (`tebi`, `adaptable-io`) were dropped during triage. Final shape: 327 valid YAMLs (300 services + 27 categories), 335 pages built.
- **Brand-colored cards** — 196 of 300 services carry real `brand_color` from simpleicons.org with tinted SVG logos. The residual ~104 use the lobe-icons / devicon / selfh.st / colored-brands cascade in story 3.7 (in flight).
- **Subcategory rendering on category pages** — `/category/<slug>` lays out three sections (Permanent Free Tiers / Free Credits & Trial / Severely Limited) matching the structure of the legacy MD tables. Empty sections skipped; counts visible per section.
- **Schema bumps** — optional `facets` block (18 fields: quotas, capabilities, restrictions, trial/credit info, operational support) plus optional `sources` block (per-record provenance for `pricing`, `brand`, and per-field `overrides`). Both additive — none of the 300 existing YAMLs break.
- **Pricing-drift verification (story 3.11 first run)** — 6 sub-agents ran a curl-based text-presence sweep across all 300 services. Output: `data/pricing-verify-report.json` (300 records) + `docs/sprints/sprint-3-pricing-drift.md` (triage). Pass rate: 73% (real-drift candidates: 51; likely-false-positive: 16; weak sunsets: 8 — all confirmed false positives on review; bot-blocked: 10; needs-JS: 2; errors: 3). Playwright upgrade for JS-rendered pages defers to Sprint 4.
- **Catalog re-verification** — 60 services confirmed-pass with `date_verified` bumped to `2026-05-15`; 16 services updated for real drift. Notable: Mixpanel free tier 20M → 1M events/month; Cloudflare Workers AI pay-as-you-go corrected from $0.50/1M → $0.011/1K neurons (22× error); Argos CI renamed "Free" → "Hobby"; Koyeb switched from always-free to credit-based; POEditor free tier shrank 30k → 1k strings.
- **URL fixes** — `netlify-dns` pricing URL was 404 → fixed; `orama` switched from JS-rendered docs to static `/pricing`.
- **SEO & syndication** — sitemap (`sitemap-index.xml`, `sitemap-0.xml`, 336 entries via `@astrojs/sitemap`), RSS feed (`/rss.xml`, 50 most-recently-verified), Schema.org `SoftwareApplication` JSON-LD on every `/service/<slug>` page.
- **Legacy Markdown retired** — `categories/*.md` deleted (story 3.12); `README.md`, `CONTRIBUTING.md`, and `CLAUDE.md` rewritten to describe the YAML-first workflow (story 3.10).
- **Production cut-over** — _deferred to a later release per user direction; the Astro build serves preview at the `rebuild/astro` branch; `freestack.is-a.dev` still points at the v1.0.0 MD-era site._

## Notable design choices

- **Free-tier is the only product**, still. Subsection grouping makes the distinction between *permanent* free tiers, *expiring credits*, and *severely limited* explicit on every category page. Paid plans appear only in the per-service `pricing` table and the JSON-LD `Offer`.
- **Text-presence pricing verification, not strict scraping.** Pricing pages reshape weekly; a CSS-selector scraper would break in days. Playwright reads the rendered text, normalizes it, and asks "do the values I claimed still appear?" — robust to layout reshapes, fragile only to genuine drift.
- **No new tracking, no `?ref=`, no analytics scripts.** Visitor count remains zero, by design (Cloudflare Web Analytics lands as opt-in in Sprint 5).

## Migration impact for contributors

- **All future service edits go through YAML.** Open `src/content/services/<slug>.yml`, edit, run `pnpm validate && pnpm audit-services --no-http`. The legacy MD edit workflow is gone.
- **Adding a service**: `pnpm new:service <slug>` scaffolds a stub YAML; see `CONTRIBUTING.md` for the full submission flow.
- **CI gates**: `pnpm lint && pnpm validate && pnpm check-logos && pnpm audit-services --no-http && pnpm build` must all pass on every PR.
- **`pnpm verify-pricing`** runs on a monthly cron once Sprint 5 story 5.3 ships; for now it's a sprint-time gate.

## Breaking changes

- **`categories/*.md` deleted.** Anyone scraping the raw Markdown files needs to switch to the YAML at `src/content/services/`, the build artifact `data/index.json` (attached to this release), or the RSS feed.
- **URL surface expanded.** New routes per service and per category: `/service/<slug>`, `/category/<slug>`. Old URLs (anchor links into `docs/index.html`) get 301-redirects via Cloudflare Page Rules — verify against `docs/redirects.md` (added in story 3.13).
