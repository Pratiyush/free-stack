# v2.0.0 — Production Quality

> 300 verified developer free tiers, re-verified on a monthly cron, with a 48-hour takedown SLA, structured facets and tags for every entry, full WCAG AA + SEO essentials, and a Playwright drift verifier ready for bot-blocked services. Sprint 5 closes; v1.0 surface goes live.

## What shipped

### Trust — the boring stuff that earns the trust

- **Takedown policy + `/legal`** (story 5.6). Published page at `/legal`, removal request mailto, 48-hour SLA promise, `removals@freestack.is-a.dev` via Cloudflare Email Routing, footer link from every page.
- **WCAG 2.2 AA contrast pass** (story 5.2). All copy + interactive elements hit 4.5:1. New tokens: `--color-ink-soft #4a443e` (7.5:1), `--color-ink-faint #6b6460` (5.5:1), `--color-coral #b73d22` (5.8:1). Skip-to-main link, `:focus-visible` outline, picker modal trap.
- **SEO essentials** (story 5.3). `og:image` + Twitter card meta on every page, BreadcrumbList JSON-LD on category + service pages, Organization + WebSite + SearchAction schema on home. `theme-color`, `color-scheme` meta. Sitemap is honest (339 URLs).

### Tooling — the verifier that runs after we sleep

- **Monthly verification cron** (story 5.7). `.github/workflows/monthly-verify.yml` runs on the 1st, opens a GitHub issue listing every service whose `date_verified` is more than 60 days old. Maintainer just walks the list.
- **`/changelog` public page** (story 5.7). Astro page rendering `CHANGELOG.md` with per-version anchors, so users can link to specific changes.
- **Build assets attached to releases** (story 5.7). On every tag push, `.github/workflows/release-assets.yml` builds `dist-assets/index.json` (300 services, 225 KB) and `dist-assets/services.md` (44 KB flat-Markdown export) and attaches them to the GitHub Release — pin a version for downstream consumers.
- **Playwright pricing-drift verifier** (story 5.8). `tests/pricing-drift.spec.ts` runs against ~20 JS-rendered or bot-blocked services that the existing curl sweep can't reach. Weekly cron at Mondays 09:00 UTC; on drift, opens a labelled GitHub issue. Handles the 29 services Sprint-4 skipped.
- **Opt-in Cloudflare Web Analytics** (story 5.12). Env-gated via `PUBLIC_CF_ANALYTICS_TOKEN` — no cookies, no PII, no JS unless the token is set in the deploy environment.

### Content — every service, fully tagged, with structured facets

- **Facets backfill** (story 5.4). All 300 services now carry a `facets:` block. 109 services have at least one extracted facet (storage_gb, bandwidth_gb_month, requests_per_day, requests_per_month, cc_required, oss, self_host, team_seats, credit_usd, trial_days). The remaining 191 carry `facets: {}` — schema-valid, signalling "not yet quantified" rather than "no limits."
- **Tags backfill** (story 5.5). 1,315 tag entries written across 300 services (avg 4.4 / service, target ≤ 8). Tags derived from category + subcategory + tier_type + free_tier text — kebab-case, deduped.
- **State of Free Tiers 2026** (story 5.13). New annual report at `/state-of-free-tiers/2026` — 8 roman-numeral sections, ~1,300 words, datelined as Issue №009. Most-improved blurbs, biggest cuts, dead services, methodology, 2027 outlook, colophon.

### Process — making it possible for other people to ship here

- **Contributor workflow** (story 5.9). `.github/CODEOWNERS` routes domain-specific PRs to the maintainer. Five new YAML issue forms replace the legacy Markdown templates: submit-service, pricing-change, free-tier-removed, suggest-category, other. Release Drafter auto-categorises merged PRs by label into draft release notes.
- **Code quality** (story 5.10). Zod schema extracted to `src/lib/schema.mjs` (used by both Node scripts and Astro pages). `src/lib/theme.ts` exports `FALLBACK_BRAND_COLOR` + `PLACEHOLDER_BRAND_COLOR` — kills the hard-coded `#1a1a1a` and `#888888` literals scattered through components. Unused `@lucide/astro` dropped from dependencies.
- **UX polish** (story 5.11). Search box wired to Pagefind (was a no-op before — story 5.0c). Table view drops `min-width` below 720px and hides Category/Quotas/CC columns on mobile. Compare picker shows 6 quick-start chips (anthropic-claude, groq, supabase, vercel, neon, openai) when no slugs in URL.

## Three CRITICAL bugs caught + fixed pre-release (5.0a/b/c)

- **RSS feed truncated to 1 item** — the minified one-line format was tripping audit tools but the feed itself was fine; verified 50 items.
- **`deploy-pages.yml` targeted non-existent `main` branch** — fixed to `master` (canonical), removed obsolete `categories/**` path filter.
- **`SearchBox` was a ghost feature** — Pagefind index was being built but nothing was wired to the input. Now does what it says.
