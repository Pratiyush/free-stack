## Why free-stack?

Existing free-for-dev lists are great but have problems:
- Giant single-file lists that are hard to navigate
- No verification — entries go stale and nobody notices
- Missing rate limits and actual constraints
- No structured format — inconsistent descriptions

**free-stack** fixes this with:
- **One file per category** — find what you need fast
- **Structured tables** — consistent columns for every entry
- **Verified dates** — each entry checked and timestamped
- **Rate limits included** — actual API/usage limits documented
- **Community-driven** — clear contribution guidelines and templates

## Table Format

Every category file uses this consistent format:

| Service | Free Tier | Limits | Rate Limits | Verified | Link |
|---------|-----------|--------|-------------|----------|------|
| Service Name | What you get for free | Specific limitations | API/usage limits | ✅ YYYY-MM | [site](url) |

---

## Rules

- **Free tier only** — not free trials. Must be free for at least 1 year.
- **SaaS/PaaS/IaaS only** — no self-hosted software.
- **Verified** — every entry must include the date it was last verified.
- **Concise** — 1-2 lines max per service description.
- **No duplicates** — each service appears in one category only.
- **Active only** — discontinued or sunset services are removed.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for guidelines.

**Quick start:**
1. Fork this repo
2. Add your service to the correct category file
3. Follow the table format exactly
4. Include a verified date
5. Open a PR with a clear title: `add: [service-name] to [category]`
