## Why free-stack?

Other lists dump everything in one giant README. We don't.

- **One file per category** — find what you need in seconds
- **Tables with specific limits** — not vague "free tier available"
- **Rate limits documented** — missing from every other list
- **Verified dates** — you know if the info is current
- **Dead services removed** — PlanetScale, Heroku, SendGrid, ElephantSQL gone

## Table Format

Every category uses this consistent format:

```
| Service | Free Tier | Limits | Rate Limits | Verified | Link |
```

---

## Rules

- **Free tier only** — not free trials (unless clearly marked)
- **SaaS/PaaS/IaaS only** — no self-hosted software
- **Verified** — every entry includes verification date
- **Specific limits** — numbers, not "limited"
- **No duplicates** — each service in one category only
- **Active only** — discontinued services are removed

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for full guidelines.

**Quick start:**
1. Fork this repo
2. Add your service to the correct category file
3. Follow the table format exactly
4. Include a verified date (current month)
5. Link to the **pricing page**, not the homepage
6. Open a PR: `add: [service-name] to [category]`
